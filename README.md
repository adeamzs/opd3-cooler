# 
This is a clip on cooler for a oneplus pad 3. It uses a cold plate,thermal pads to transfer heat heat to a finstack where a fan blows on the finstack. The whole thing is powered by an 18650,theres a charging module and a buck step up for the 12v that the fan needs.

The 3d print has a mount for a 92mm fan,meshes for airflow. The top mesh is made so you can slide it out and in,replace it or to reach the internals. On the right side is the case for electronics,which also opens by a sliding mechanism.

The fan can be oriented to either pull or push air.Either way, the air will go over the finstack. Pull is better for ergonomics while push is better for performance,altho the gains are rather small.
