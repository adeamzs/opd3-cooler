# 
This is a clip on cooler for a oneplus pad 3. It is used for cooling of the SoC (cpu,gpu,ram..) so that when you do heavy tasks like in my case emulating pc games,youre able to push higher clock speeds and have better temperatures,which increase the lifespan of the SoC.

The 3d print has a mount for a fan,meshes for airflow. The top mesh is made so you can slide it out and in or replace it. On the right side is a case for electronics,which also opens by a sliding mechanism.

The fan can be oriented to either pull or push air.Either way, the air will go over the finstack. Pull is better for ergonomics while push is better for performance,altho the gains are rather small.
